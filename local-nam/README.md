# Nām (local)

1. Put `names_list.txt` in this folder (one name per line). If it is missing, a short sample list is used.
2. Install and run:

```
pip install -r requirements.txt
python app.py
```

3. Open http://127.0.0.1:5000

Profiles (id, phone, address) are generated locally and stored in `directory.db`. They are fake.
